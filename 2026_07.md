# FSAE Telemetry Simulator — Complete Documentation (July 2026)

---

# 1. Project Overview

Formula SAE telemetry system with real-time simulation, multi-lap race generation, Streamlit dashboard, driver analysis, live coaching recommendations, and F1 real-telemetry integration.

**Key capabilities:**
- Real-time vehicle physics simulation (10 Hz)
- Multi-lap batch simulation
- 19-page Streamlit dashboard for live telemetry, replay, lap analysis, track design, driver profiling
- ML-based recommendation engine (RandomForest segment policies)
- Live coaching assistant with per-segment feedback
- FastF1/OpenF1 integration for real F1 telemetry
- Physics calibration pipeline against real data

# 6. Physics Model (Simple)

## Longitudinal Dynamics

```
drag            = 0.5 * ρ * Cd * A * v²
rolling_resist  = Crr * m * g
engine_force    = F_max_engine * throttle
brake_force     = F_max_brake * brake
net_force       = engine - brake - drag - rolling
acceleration    = net_force / m
v_new           = max(0, v + a * dt)
```

## Yaw Dynamics

```
sensitivity = 30.0 / max(speed_kmh / 40.0, 1.0)   # deg/s
yaw_rate    = steering * sensitivity
```

## Thermal Model

```
heat_gen  = throttle * 0.8
speed_heat = speed_kmh * 0.01
cooling   = 0.08 * (speed_kmh / 40.0)
temp_new  = temp + (heat_gen + speed_heat - cooling) * dt * 10
```

## Track Following (GPSMock)

Points move along a closed loop of (x,y) waypoints. Distance traveled interpolates between waypoints. Lap completion detected when within `lap_threshold=2.0` units of start point, with cooldown to prevent double-counting.

# 7. Sensor Models

All current sensors take a `true` value and return a noisy reading with optional dropout.

| Sensor | Input | Output | Noise | Dropout |
|--------|-------|--------|-------|---------|
| `WheelSpeedSensor` | true speed (km/h) | noisy speed (km/h) | Gaussian(std) | None on dropout |
| `BrakePressureSensor` | true brake_cmd * 100 | pressure (bar) | Gaussian(std) | None on dropout |
| `CoolantTempSensor` | true temp (°C) | noisy temp (°C) | Gaussian(std) | None on dropout |
| `IMUSensor` | true_ax, true_ay, true_yaw | {ax, ay, yaw} | Per-axis Gaussian(std) | None on dropout |

Noise models: `gaussian_noise(mu=0, sigma)`, `occasional_dropout(prob)`.

Legacy sensors (`simulator/sensors/`) use hardcoded sine waves and random events — kept for backward compatibility.

# 10. Recommendation Engine

## Data Flow

```
logs/*.json
  → load_all_sessions()
  → build_segment_database()    # groups by track_index
  → best_action_per_segment_by_best_lap()  # policy = best recorded action
  → OR train_regressors_per_action()       # RandomForest per action
  → recommend_action_segment(segment_idx, state_vector)
```

## Live Coaching

```
logs/*.json
  → build_segment_reference()   # per-segment target speed/throttle/brake
  → recommend_for_packet(packet, segment_ref)
    → compares current vs target
    → returns coaching messages: ["Speed up", "Brake earlier", ...]
```

**Streamlit pages** 16-19 display these recommendations live.

# 12. Physics Calibration

## `simulator/calibrate_from_f1.py`

Tunes car parameters against real F1 speed traces using scipy optimization.

**Pipeline**:
1. Load real lap data (converted via FastF1/OpenF1)
2. Run FSAE physics with real throttle/brake traces
3. Compute speed RMSE between simulated and real
4. Optimize 6 parameters with L-BFGS-B:

| Parameter | Bounds | Default |
|-----------|--------|---------|
| `mass` | 150-400 kg | 210 |
| `drag_coeff` | 0.3-1.5 | 0.9 |
| `frontal_area` | 0.5-2.0 m² | 1.0 |
| `rolling_resistance` | 0.005-0.04 | 0.015 |
| `max_engine_force` | 3000-12000 N | 6000 |
| `max_brake_force` | 500-3000 N | 1500 |

5. Save calibrated params to `car_simple_calibrated.yaml` or apply to live config
6. Generate per-lap validation report (MAE/RMSE/sector errors)

**CLI**:
```bash
python simulator/calibrate_from_f1.py --lap-file data/logs/f1_VER_*.json --calibrate --report
python simulator/calibrate_from_f1.py --lap-file data/logs/f1_VER_*.json --eval
python simulator/calibrate_from_f1.py --lap-file data/logs/f1_VER_*.json --calibrate --apply
python simulator/calibrate_from_f1.py --lap-file data/logs/f1_VER_*.json --calibrate --save my_params.yaml
```

# 17. Error Handling & Edge Cases

- **Sensor dropout**: All sensors return `None` on dropout. Dashboard handles `None` values gracefully.
- **JSON atomic writes**: `atomic_write()` uses tmp-file + os.replace with retry fallback.
- **Stop signal**: Simulator checks `data/stop_signal.txt` for graceful exit.
- **Missing track files**: Falls back to oval track.
- **No session logs**: Recommender falls back to heuristic profiles.
- **FastF1 not installed**: Functions return `None`, print install instructions.
- **OpenF1 rate limit**: ~250 req/hr; `OpenF1Stream` polls at 0.5s intervals.
- **Calibration failure**: L-BFGS-B may fail to converge; prints error, returns current best.
